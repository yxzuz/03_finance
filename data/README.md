# Dataset Information

The credit card dataset (`creditcard.csv`) is not included in this repository due to GitHub's file size limits (143.84 MB exceeds 100 MB limit).

## How to get the dataset:

1. **Kaggle Dataset**: Download from [Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud/data)
2. **Place the file**: Put `creditcard.csv` in the `data/` directory
3. **File structure should be**: `data/creditcard.csv`

## Dataset Details:
- **Size**: 284,807 transactions
- **Features**: 31 columns (Time, V1-V28, Amount, Class)
- **Class Distribution**: Highly imbalanced (0.17% fraud rate)
- **File Format**: CSV

## Alternative:
You can use any similarly structured credit card fraud dataset with the same column names and format.
